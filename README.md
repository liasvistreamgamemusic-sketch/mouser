# Mouser

一定間隔でマウスカーソルを自動で動かす macOS 用メニューバーアプリ。
スリープやスクリーンセーバ、「離席中」表示の抑止に使う。外部依存なし (SwiftUI 単一ファイル)。

## 機能

メニューバーのカーソルアイコンをクリックすると設定パネルが開く:

- **オン / オフ** — トグルスイッチで切り替え (アイコンの見た目も変わる)
- **間隔** — 5〜300 秒 (デフォルト 60 秒)
- **移動距離** — 5〜200 px (デフォルト 20 px)。ランダムな方向へ滑らかに動いて元の位置に戻る

設定は自動保存され、次回起動時も引き継がれる。

## インストール

[Releases](../../releases) から `Mouser-x.y.z.zip` をダウンロードして展開し、
`Mouser.app` をアプリケーションフォルダなどに置いて起動する。

ad-hoc 署名のため、初回はそのまま開けず Gatekeeper に止められる。
いずれかの方法で回避する:

```sh
xattr -dr com.apple.quarantine Mouser.app
```

または「システム設定 → プライバシーとセキュリティ」下部の「このまま開く」。

## 権限

権限なしでもカーソル自体は動く (`CGWarpMouseCursorPosition` を併用しているため)。

ただしスリープ・スクリーンセーバ・「離席中」表示の抑止まで効かせるには、
OS にマウスイベントとして認識させる必要があり、**アクセシビリティ権限**が要る。
トグルをオンにしたときに許可ダイアログが出るので、
「システム設定 → プライバシーとセキュリティ → アクセシビリティ」で Mouser を許可する。

## ソースからビルド

```sh
./build.sh          # Mouser.app を生成 (バージョン 0.0.0-dev)
./build.sh 0.0.1    # バージョンを指定して生成
open Mouser.app
```

要件: macOS 13 以降、Xcode Command Line Tools。

## リリース手順

`v*` タグを push すると GitHub Actions がビルドして Release を自動作成する:

```sh
git tag v0.0.2
git push origin v0.0.2
```
